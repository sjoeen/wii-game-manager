Wii SD Manager · v3.0.0

Important Information

Your SD card. Your files. All on your device.

1. Open an existing Wii card

Choose Open SD / USB and select the card’s root folder, or a backup of it. It should contain apps/, wbfs/, or other Wii folders. Your Wii’s homebrew and loader setup must already exist. This manager does not prepare, format, or install homebrew on an empty card.

Folder mode lists file metadata, stages your changes, and copies added games in 4 MiB chunks. The combined library is not capped at 4 GiB. The number of games is not capped. Existing homebrew cards with no games yet are supported.

Use Review & apply to inspect every affected path. Only the final Apply to selected folder button starts disk changes. Unrelated apps, saves, and settings stay in place.

2. Which files should you choose?

Folder, game, and ZIP controls accept different inputs. Open a section for accepted files, folder examples, and what is not supported. Renaming a file’s extension does not convert it.

3. Backup, filesystem, and recovery

Keep a separate backup and do not unplug the card during Apply. Pending edits have one-step Undo and Discard; applied removals are permanent. Writes are copied and read back for a CRC32 check before any removals begin. Replaced files have disk-backed rollback copies; an interrupted operation offers recovery when the folder is reopened.

Recovery cannot make a multi-file change atomic or protect against a failed card. Do not edit the same files in another app while applying changes. Extra free space is needed for writes, native temporary files, and replacement backups. The browser cannot reliably tell this app how much free space your SD card has.

FAT32 still limits each file. Oversized WBFS files with a WBFS header are copied as byte-contiguous parts of at most 2 GiB. Large ISO files must be converted to suitable WBFS files outside this tool; renaming is not conversion. The source game file is never changed.

4. Small-ZIP fallback

Open small ZIP instead keeps the earlier archive editor. It is limited to below approximately 4 GiB uncompressed and may run out of memory below that. Use it for small homebrew/mod archives, not whole game collections. Export creates a new ZIP and does not write to your card; copying an export over old files does not remove deleted files.

ROM-hack ZIP packages in folder mode are limited to 256 MiB uncompressed. Larger ready-patched game files belong in Add Game. Untracked Riivolution removal only includes its XML and matching folder; other patch locations are left alone.
